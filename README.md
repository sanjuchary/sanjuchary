## 🚀 Spotlight: QwkPay

<div align="center">

> **Reimagining retail checkout for India 🇮🇳**
>
> QwkPay is a smart self-checkout billing system for supermarkets like D-Mart, Reliance Smart & Ratnadeep.
> Customers scan → pay → exit. Zero queues. Zero friction.

| App | Stack | Status |
|:----|:------|:------:|
| 🛒 User App | React Native + Expo | 🟡 In Dev |
| 🏪 Merchant Dashboard | Next.js + Supabase | 🟡 In Dev |
| 🛡️ Guard Verify App | React Native | 🟡 In Dev |
| 📊 Admin Panel | Next.js + PostgreSQL | 🟡 In Dev |
| 🌐 Landing Page | Next.js + Tailwind | 🟢 Live |
